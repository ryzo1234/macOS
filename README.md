# iOS 26 w przeglądarce

Prototypowy interaktywny ekran główny inspirowany iOS 26. Projekt działa w całości w przeglądarce i prezentuje nowoczesny wygląd wraz z kilkoma funkcjami demonstracyjnymi.

## Funkcje
- Aktualizowany w czasie rzeczywistym zegar oraz dynamiczny widżet pogody.
- Interaktywne centrum sterowania z przełącznikami i suwakami.
- Centrum powiadomień z przykładowymi komunikatami.
- Siatka aplikacji i dock z oknami modalnymi przedstawiającymi treści demo.
- Panel boczny z szybkimi akcjami, które logują wydarzenia w dzienniku systemowym.

## Uruchomienie
Otwórz plik `index.html` w dowolnej nowoczesnej przeglądarce. Nie są wymagane dodatkowe zależności ani serwer.
